# AI 初剪工作台

自动初剪口播视频，再由你审核、重剪并导出。

导入原片后，工具自动转写，识别重说、卡壳、语气词等片段，生成第一版成片。你可以逐条决定“保留 / 剪掉”，也可以补充要求，让 AI 从原片重新剪一版。

**[下载 Windows 安装程序](https://github.com/J0n-Pan/ai-firstcut/releases/latest)**（推荐，可覆盖升级旧版，自动保留工程与设置） · [免安装版](https://github.com/J0n-Pan/ai-firstcut/releases/latest) · [详细使用文档](docs/usage.md)

## 一句话使用

把这段话发给你的 Agent（需支持操作本机）：

```text
请帮我在这台 Windows 电脑上安装并运行 AI 初剪工作台：
https://github.com/J0n-Pan/ai-firstcut
从 Releases 下载最新版 Windows 安装包（或免安装版），完成安装或解压，
在我的 Windows 桌面中启动并打开工作台，保留已有工程与设置，
确认页面可用，需要 API Key 时引导我在页面中自行填写。
```

## 开始使用

1. 运行下载的 `AI-FirstCut-Studio-*-Setup.exe`，选择安装位置（默认装在当前用户目录，不需要管理员权限）。也可以下免安装版，解压后双击 `启动 AI初剪工作台.cmd`。
2. 浏览器会打开 [本地工作台](http://127.0.0.1:5179)。填入自己的 [阿里云百炼（DashScope）API Key](https://bailian.console.aliyun.com/)，点击“保存到本机”。
3. 拖入视频，等待自动初剪。支持 MP4、MOV、MKV。
4. 在预览和审核列表中检查结果，选择“保留 / 剪掉”，点击“应用并重剪”。成片默认保存在 `exports/` 文件夹。

无需手动安装运行环境；首次剪辑会联网下载所需依赖。使用时请保留启动窗口，关闭窗口会退出服务。

## 继续调整

- **按审核决定重剪**：保留已有分析结果，生成一版新的成片。
- **重新 AI 剪辑**：点击顶部“AI 剪辑”，补充一句要求，例如“删掉开头的闲聊”，从原片重新分析。
- **对比版本**：切换历史成片，检查修改效果。

## 使用前了解

- 默认转写和 AI 判断需要联网。提取的音频和相关转写文本会发送至云端；API Key 保存在本机 `.env` 文件中，用于服务鉴权。
- 当前只做视频初剪，不含字幕烧录、动效和章节页。输出为 8bit，不保证保留 10bit / HDR。
- 源码运行、配置、数据管理和常见问题见 [使用文档](docs/usage.md)。
